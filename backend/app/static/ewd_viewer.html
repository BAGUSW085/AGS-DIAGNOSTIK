🎨 Legenda Kode Warna Kabel Standar OEM

Format 2 warna (garis strip): huruf pertama = warna dasar kabel, huruf kedua = warna garis strip. Contoh: B/W atau B-W = Hitam garis Putih.
B / BLK — Hitam
W / WHT — Putih
R / RED — Merah
G / GRN — Hijau
L / BLU — Biru
Y / YEL — Kuning
BR / BRN — Cokelat
GR / GRY — Abu-abu
LG / LT GRN — Hijau Muda
O / ORN — Oranye (HV!)
P / PNK — Pink
V / PPL — Ungu
