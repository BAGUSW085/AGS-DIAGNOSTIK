# Cara Mengambil & Memasang APK Offline AGOS Smart Diagnostik v2.2.0 di HP Android

Aplikasi **AGOS Smart Diagnostik (Mode Offline v2.2.0)** telah diperbarui penuh sesuai **PRD v2.2.0 (`REQ-01` s/d `REQ-14`)** dengan **logo ikon resmi AGOS** agar berjalan **100% tanpa internet dan tanpa server**.

### Pembaruan Utama pada APK Offline v2.2.0:
- **8 Paket Buku Manual OEM Aktif:** 2.511 DTC, 6.315 Pinout ECU, dan 2.477 Spek Sensor (Suzuki Grand Vitara JB420, Suzuki Ertiga K14B/D13A, Toyota Avanza/Xenia, Fortuner, Innova, Hilux/HiAce, Yaris/Vios, Corolla/Camry/Alphard).
- **Simulator Wiring Multi-Sumber v3 & Wiring Viewer Interaktif BYOD:** Akurat per pinout OEM (B+, IG, ECM, Ground), Deep-Link langsung dari diagnosa, modal **Kode Warna Kabel OEM**, guardrail keselamatan **Mode Ohm** & **HV 1000V Hybrid/EV**, serta buka file `.pdf`/`.svg`/`.svgz` lokal dari HP.
- **Express Search Kilat (< 100ms) & Weighted CBR Berbobot:** Pencocokan kasus termirip berbasis 6 variabel (Keluhan/Gejala 25%, DTC 25%, Model 15%, Kilometer 15%, Merek/Platform Kembar 10%, Tahun 10%) + Live Data Scanner + **Top 3 Kasus Pengalaman Mekanik Termirip**.
- **17 Kasus Terverifikasi + Workflow Verifikasi PIN Kepala Bengkel (`1234`) & Ekspor/Impor Excel (`DATA_KASUS_AGOS.xlsx`) 100% Offline via SheetJS Lokal.**
- **Penjelasan Bahasa Awam untuk Pemilik Mobil, Tooltip Mekanik Junior `(?)`, & Preview Tab Web POS Bengkel (Demo PPN 11% + Auto-Deduct Stok).**
- **Tampilan HP Rapi + Layar Horizontal/Vertikal:** 0 scroll samping di seluruh tab (`360px`+) & kanvas wiring mobile 77% layar.

## Langkah 1 — Mengambil File `.apk`
1. File siap pasang tersedia langsung di folder proyek Anda: **`AGOS-Smart-Diagnostik-Offline.apk`**.
2. Atau unduh langsung dari GitHub Releases:
   👉 **[https://github.com/BAGUSW085/AGS-DIAGNOSTIK/releases/tag/v2.2.0-offline](https://github.com/BAGUSW085/AGS-DIAGNOSTIK/releases/tag/v2.2.0-offline)**

## Langkah 2 — Memasang APK di HP Android
1. Kirim file **`AGOS-Smart-Diagnostik-Offline.apk`** ke HP Android Anda (lewat WhatsApp, kabel USB, atau Google Drive).
2. Ketuk file **`AGOS-Smart-Diagnostik-Offline.apk`** di HP Anda (jika sebelumnya sudah terpasang versi lama, pilih **Update / Perbarui**).
3. Jika muncul peringatan *"Instal aplikasi yang tidak dikenal"*, aktifkan **"Izinkan dari sumber ini"**.
4. Ketuk **Instal (Install)** → **Buka (Open)**.
